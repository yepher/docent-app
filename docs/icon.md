# Docent icon

Created with the built-in image generation tool. The open book's lower edge forms a speech-bubble tail; an amber bookmark represents finding the right evidence. Teal matches the application's existing accent.

Source: `build/icon-source.png`. Platform assets: `build/icon.png`, `build/icon.icns`, `build/icon.ico`. The renderer uses `src/renderer/public/icon.png`.

Final generation prompt:

> Use case: logo-brand. Create a polished desktop application icon for Docent, a private offline library assistant that answers questions from the user's documents with citations. A bold ivory open book whose pages form a subtle speech bubble, with a small warm amber bookmark suggesting a guide to knowledge. Deep teal rounded-square tile, restrained dimensional depth and soft lighting, crisp strong silhouette readable at 32px. Centered single icon, generous safe margin, square 1024x1024 image. No letters, no text, no robot, no cloud, no magnifying glass, no decorative sparkles, no mockup. Transparent outside the rounded tile.

The generated source was resized and packaged as PNG, ICNS and ICO; its artwork was not otherwise edited.
